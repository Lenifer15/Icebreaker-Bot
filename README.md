# 🤖 AI Icebreaker Bot

## 📌 Project Overview
An AI-powered tool that generates personalized conversation starters using LlamaIndex and IBM Granite. It analyzes user-related data to help initiate meaningful and engaging conversations in networking and social settings.

---

## 🚀 Features
- 🤖 Generate personalized icebreakers instantly
- 🔍 Smart data retrieval using LlamaIndex
- 🧠 Powered by IBM Granite for text generation
- 🎯 Context-aware and relevant suggestions
- ⚡ Simple and fast setup

---

## 🧠 Technologies Used
- Python
- LlamaIndex
- IBM Granite (watsonx)
- HTTPX
- MCP (Model Context Protocol)

---

## ⚙️ How It Works
1. Input a name or profile
2. Retrieve relevant data using LlamaIndex
3. Process context and extract insights
4. Generate responses using IBM Granite
5. Output personalized icebreakers

---

## 🛠️ Installation
git clone https://github.com/your-username/ai-icebreaker-bot.git
cd ai-icebreaker-bot
uv venv
.venv\Scripts\activate
uv add "mcp[cli]" httpx llama-index
